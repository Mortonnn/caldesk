## 为什么还没有代码

小程序的数据通道有三条路，选哪条决定代码结构，需要你拍板：

| 方案 | 小程序端如何取数据 | 上线前要做什么 |
|---|---|---|
| A 备案域名 | `wx.request` 打 Cloudflare Worker | 域名 ICP 备案（1–3 周） |
| B 微信云开发 | `wx.cloud` 直连云数据库 | 无需备案，但数据存腾讯云 |
| C PWA 过渡 | 不做小程序，手机浏览器访问 Pages | 无需备案，立即可用 |

## 开发阶段的一个便利

`project.config.json` 里已经设了 `"urlCheck": false`（对应开发者工具「不校验合法域名」）。
这意味着**开发阶段可以直接连 `*.workers.dev` 调试**，不必等备案；只有正式发布（上传体验版之后提审）
才必须换成已备案域名。
