# caldesk 部署与安装

分三步：部署云端（一次性）→ 装桌面端 → 装安卓端。

---

## 零、整体结构

```
桌面端 (Electron)  ──┐
                      ├──▶  Cloudflare Worker  ──▶  D1 数据库
安卓端 (Capacitor) ──┘        (公网 HTTPS)
```

- **没有自建后端服务器**，云端就是一个 Cloudflare Worker + D1，免费额度够用。
- **服务端存明文**（这是有意的取舍：简单方便）。隐私靠账号隔离保证：
  - 账号 = 用户名 + 密码（PBKDF2-HMAC-SHA256 加盐哈希，不存明文）；
  - 登录后每台设备一套凭据，服务端只存 `sha256(salt || secret)`，明文 secret 不落库；
  - **任意设备登录同一个账号即同步**，不再需要配对码或批准；
  - 每次读写都按 `account_id` 过滤，跨账号看不到对方数据；
  - 设备可以在任意一端随时**撤销**。
- 桌面端数据在本地 SQLite；手机端直接读写云端（在线优先）。

## 一、部署 Cloudflare Worker

推荐 **GitHub 自动构建**（改代码 push 即自动部署）。

### 方式 A：GitHub 自动构建（推荐）

1. 把本仓库推到一个 GitHub 私有仓库。
2. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Connect to Git**。
3. 授权 GitHub，选中仓库。
4. 填构建配置：

   | 项 | 值 |
   |---|---|
   | Production branch | `main` |
   | Build command | `npm ci` |
   | Build output / Root directory | `worker` |
   | Deploy command | `npx wrangler deploy` |

   > Root directory 必须是 `worker`——Worker 的源码在 `worker/` 子目录里，
   > 这样构建上下文才能带上 `worker/package.json` 和 `worker/wrangler.toml`。

5. 点 **Save and Deploy**。构建成功后 Worker 就上线了。
6. 以后每次 `git push` 都会自动重新部署。

### 方式 B：本地 wrangler 部署

```powershell
cd worker
npm install
npx wrangler login          # 浏览器里点允许

# 建 D1 库（第一次）
npx wrangler d1 create caldesk
# 把输出的 database_id 填进 worker/wrangler.toml

# 建表
npx wrangler d1 migrations apply caldesk --remote

# 发布
npx wrangler deploy
```

### 自检

```powershell
curl https://你的地址/health
# 期望：{"ok":true,...}
```

### 自定义域名

Dashboard → 你的 Worker → **Settings** → **Triggers & Custom Domains** → 添加。

添加后 `https://你的域名` 就能用。客户端里填这个地址。

> ⚠️ 已知问题：某些 Cloudflare 账号下 `*.workers.dev` 这个访问路径会返回 **1101**，
> 但同一个 Worker 挂在自定义域名上完全正常。遇到 1101 请改用自定义域名。

### 不需要 SYNC_TOKEN

早期版本靠一个共享令牌，现在改成了**账号密码 + 每设备一套凭据**，
服务端不再有全局令牌，也就没有"令牌泄露=全军覆没"的问题。

## 二、桌面端

1. 运行 `caldesk-0.1.0-setup.exe` 安装。
2. 打开后点齿轮 → **同步**。
3. 填你自己部署的 Worker 地址（`https://<你的域名>`）；仓库里不预置任何人的服务器。
4. 点「注册」：用户名随意，密码至少 10 位且含大小写、数字、符号（有「生成强密码」按钮）。
5. 注册成功即登录，点「立即同步」把本地数据推上去。
6. 手机端用**同一个用户名密码登录**，不需要扫码或配对。

> 从旧版本升级上来的账号还是"配对时代"的：设置里会多出「设置账号密码」一栏，
> 设一次之后其他设备就能用新密码登录，**原有数据一行不动**。

同步行为：
- 启动后自动同步一次；
- **本地一有改动，3 秒后自动推送**（不用等定时同步）；
- 每 5 分钟再全量对一次账；
- 拉到的远端改动会立刻刷新主窗口和桌面浮窗。

## 三、安卓端

1. 把 `caldesk-debug.apk` 传到手机安装（允许"未知来源"）。
2. 首次打开是「登录 caldesk」页：填服务器地址、用户名、密码，直接登录或注册。
3. 登录即同步；设置页里可以退出登录、增删日历、改服务器地址。
4. 设备名默认是 `机型_月日时`（例如 `24129PN74C_110415`），在设备列表里能分清谁是谁。

### 手机界面

- 底部是**液态玻璃 dock**：左边约 3/4 是玻璃导航（日历 / 即将 / 设置），右边 1/4 是圆形 ＋。
  手指按在玻璃上时，选中那个"药丸"会跟着手指滑过去，松手才切页。
- **翻月靠左右滑月视图**，没有 ‹ › 按钮；滑过去会保留日号（3 号滑到下个月还是 3 号）。
- 顶栏只有「年月」和右上角的**日历切换**：点开是列表式弹出卡片，当前日历右侧打勾。
- 当天列表把**任务和事件合成一个列表**：未完成在上、已完成在下，组内按创建顺序。
  只有会重复/是提醒/是倒数日时才在右边显示一个小标签，普通任务不加标签。
- 不在今天时，日期标题右侧出现胶囊形的**「今天」**按钮，一键回到今天。
- 新增任务只有两条路：右下角 **＋**，或者点列表里的条目勾选。没有"添加"文字按钮。
- 添加弹层打开时 dock 会整条收起，取消/添加不会被顶到键盘上面去。
- 「设置」里能看到当前账号下的**已登录设备**（名字带月日时，能分清谁是谁）、
  增删日历、改服务器地址、退出登录。

> `android/` 目录在 `.gitignore` 里（Capacitor 生成物）。`AndroidManifest.xml` 里给 MainActivity
> 加了 `android:windowSoftInputMode="adjustResize"`，让键盘弹出时的布局行为确定；
> 重新 `npx cap add android` 之后需要再补上这一行。

> APK 是 debug 签名，装不了正式版商店，但自己用没问题。

### 构建 APK

```powershell
npm run build:mobile       # 手机端专用构建 → out/mobile
npx cap sync android       # 同步到 android/
cd android
$env:JAVA_HOME = "D:\develop\java\jdk-21.0.13+9"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
.\gradlew.bat assembleDebug
```

产物：`android/app/build/outputs/apk/debug/app-debug.apk`

> 手机端是**独立的一套界面**（`src/renderer/src/MobileApp.tsx` + `mobile.css`），
> 和桌面端 `App.tsx` 完全分开，靠 `vite.mobile.config.ts` 单独构建。
> APK 里**不含**桌面端 bundle。

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录提示「HTTP 404」 | Worker 还是旧版，没有 `/auth/*` 接口 | 重新部署 Worker（`npx wrangler deploy`） |
| 登录提示「邀请码不正确」 | 这个 Worker 设置了 `INSTANCE_INVITE` | 在注册页填邀请码（或用 `wrangler secret` 去掉） |
| 手机 401「设备未授权」 | 这台设备被撤销，或换过服务器 | 重新登录一次（登录会重新绑定设备） |
| 服务端数据是空的 | 本地改动还没推上去 | 桌面端点「立即同步」，或等 3 秒自动推送 |
| 改完一端，另一端不变 | `/api/changes` 探针没通（旧版 Worker 没这个端点） | 重新部署 Worker；两端都升到最新版 |
| 手机启动还是闪一下白 | 旧版启动没有内联启动画面 | 升级到最新版（现在首帧就是图标） |
| 桌面设置里显示「设置账号密码」 | 这是配对时代的老账号，还没设用户名密码 | 设一次即可，原有数据不动 |
| `*.workers.dev` 报 1101 | 该账号的 workers.dev 路径有问题 | 改用自定义域名 |
| 桌面端同步「失败 1」 | 某一端数据缺字段 | 日志里有具体 id 和原因 |
| 想在浏览器直接用 | 支持 | 访问 Worker 地址没有页面，需要另外部署 |

## 五、数据在哪

| 位置 | 路径 / 说明 |
|---|---|
| 云端 | Cloudflare D1（免费额度：5GB 存储 + 每天百万级读） |
| 桌面端 | `%APPDATA%\caldesk\caldesk.db`（SQLite） |
| 桌面端身份 | `%APPDATA%\caldesk\identity.json`（accountId / deviceId / deviceSecret） |
| 手机端 | **不存本地**，直接读写云端（离线不可用） |
| 本地回滚记录 | `%APPDATA%\caldesk` 下的 `snapshots` 表，100 条上限 |

> `identity.json`、`.dev.vars`、`*.db` 都已在 `.gitignore` 里，不要提交。

node scripts/verify-online.mjs       # 对着线上 Worker 跑断言（需 CALDESK_SERVER）
npm run test:auth                    # 账号密码协议断言（本地 worker 或线上，第二个参数传邀请码）
node scripts/verify-desktop-e2e.mjs  # 驱动真实 caldesk.exe 跑完整同步
node scripts/sync-real.mjs           # 用真实 userData 跑一次同步
node scripts/probe-api.mjs <deviceId> <secret>   # 用某设备凭据打服务端 API
