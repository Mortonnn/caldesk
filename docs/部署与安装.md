# caldesk 部署与安装

分三步：部署云端（一次性）→ 装桌面端 → 装安卓端。

---

## 一、部署 Cloudflare Worker（约 10 分钟）

### 1. 登录

```powershell
cd caldesk\worker
npx wrangler login
```

浏览器会弹出授权页，点允许。

### 2. 创建 D1 数据库

```powershell
npx wrangler d1 create caldesk
```

输出里有一行 `database_id = "xxxx-..."`，把它填进 `worker/wrangler.toml` 的 `database_id`（覆盖占位符）。

### 3. 建表

```powershell
npx wrangler d1 migrations apply caldesk --remote
```

### 4. 设置同步令牌

自己想一串随机字符串（比如 32 位十六进制），然后：

```powershell
npx wrangler secret put SYNC_TOKEN
# 回车后粘贴，输入不回显
```

> 这个令牌就是"钥匙"：桌面端和手机端都要填它。**不要发到群里或提交到 git。**

### 5. 发布

```powershell
npx wrangler deploy
```

输出会给出地址，形如 `https://caldesk-sync.你的账号.workers.dev`。

### 6. 自检

```powershell
curl https://caldesk-sync.你的账号.workers.dev/health
# 期望：{"ok":true,"service":"caldesk-sync","d1":true}
```

---

## 二、桌面端

1. 运行 `caldesk-0.1.0-setup.exe` 安装
2. 打开后点右上角齿轮 → **同步（Cloudflare）**
3. 填入 Worker 地址和同步令牌 → 保存
4. 点「立即同步」，看到「完成：上传 N，下载 M」就好了
5. 之后启动会自动同步，并每 5 分钟跑一次

---

## 三、安卓端

1. 把 `caldesk-debug.apk` 传到手机（微信/数据线/网盘都行）
2. 安装时可能提示"未知来源"，允许即可
3. 首次打开会看到「连接你的日历」页
4. 填入**同一个** Worker 地址和令牌 → 连接

连上后两端数据自动一致：电脑上加的任务，手机上刷新就能看到。

---

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 手机提示"连接失败 HTTP 401" | 令牌不对 | 重新 `wrangler secret put SYNC_TOKEN`，两端都改成新值 |
| 手机提示"无法连接" | 地址写错 / 没联网 | 先用手机浏览器打开 `<地址>/health` 确认能访问 |
| 桌面端同步「失败 1」 | 某一端数据缺字段 | 日志里会带具体 id 和原因，按提示修 |
| 换手机后数据不回来 | 新设备本地为空 | 首次连接后点一次「立即同步」，或拉一次全量（`/sync/run?full=1`） |
| 想在浏览器直接用 | 支持 | 访问 Worker 地址没有页面；需要单独部署 Pages 版（暂未提供） |

## 五、数据在哪

- 云端：Cloudflare D1（免费额度：5GB 存储 + 每天百万级读）
- 桌面端：本地 SQLite，`%APPDATA%\caldesk\caldesk.db`
- 手机端：**不存本地**，每次直接读云端（离线暂不可用）

> 这是当前的设计取舍：手机端做成"在线优先"，换取两端永远一致、没有合并冲突。
> 如果以后需要离线，再给手机端加本地缓存。
