# 设计系统（caldesk 前端）

这套东西的目标不是"加一层毛玻璃"，而是让三套界面（桌面 / 手机 / 浮窗）**出自同一个设计团队**：
同一份令牌、同一套材质、同一条动效曲线。加新组件时照这份文档写，不用重新发明。

---

## 1. 层模型

从下往上四层，任何元素只属于其中一层：

| 层 | 内容 | 材质 | 说明 |
| --- | --- | --- | --- |
| **L0 环境** | 一整窗的柔光渐变 + 颗粒 | `.mat-ambient` | 只有一个元素。玻璃"看起来是玻璃"全靠它有东西可透 |
| **L1 内容** | 月历纸、日格、任务行、编辑区 | `.mat-surface`（不透明） | 不透明、不模糊。Apple 的规则：玻璃不进内容层 |
| **L2 浮层** | 弹层主体、sheet 主体、确认框 | `--panel` + 提升阴影 | 近乎不透明 |
| **L3 玻璃** | 标题栏、侧栏、详情栏、dock、FAB、菜单 | `.mat-chrome` / `.mat-glass` | 半透明 + 镜面边 + 颗粒底 |

**不变量**：玻璃必须压在 L0 或"正在移动的 L1 内容"之上。压在纯色面板上的玻璃一定是灰盒子。

## 2. 材质

### 2.1 四种材质类（`src/renderer/src/design/material.css`）

| 类 | 用途 | 组成 |
| --- | --- | --- |
| `.mat-ambient` | 全窗一层 | 3 个低振幅径向渐变 + 128px 颗粒 + 顶部暗角 |
| `.mat-surface` | 内容面 | 不透明底色 + 发丝内描边 |
| `.mat-chrome` / `.mat-chrome-flat` | chrome 层 | 白色渐变（体感上亮下暗）+ 半透明墨 + 顶高光 / 底暗边 + 外阴影 |
| `.mat-glass` | 需要真模糊时叠加 | `backdrop-filter: blur() saturate(180%)` |

**镜面边用内阴影堆，不用 `border-image` / `mask-composite`**：圆角天然正确、没有亚像素偏差、兼容到极老的 WebView，而且不占用 `::before` / `::after`（组件自己的高光、删除线还要用）。

### 2.2 深色不是"浅色反色"

四条必须同时成立，否则就是灰盒：

1. **底色用偏蓝的墨** `rgba(12,14,18,.66)`，不是纯黑 —— 纯黑半透明会比页面更暗。
2. **亮度是"加"上来的**：`--mat-grad` 里的白色渐变把面抬高 6–12 L\*。合成后必须比背后的面亮，否则读作"被禁用"。
3. **`saturate(180%)` 是模糊补偿**，不是风格旋钮：高斯模糊把每个像素推向局部均值（彩色图的均值是中灰）。低于 140% 发脏，高于 220% 色阶断裂。
4. **暗角锚在顶部中央**，和光源方向一致；锚在正中会变成聚光灯。

统一光源：上方偏左 25° 的远方向光。推论：顶边永远最亮、只有底边是暗边、阴影永远向下偏且宽而淡。

### 2.3 三档降级（`design/platform.ts`）

启动时写 `<html data-mat>` / `<html data-glass>`：

| 档 | 触发 | 效果 |
| --- | --- | --- |
| `full` | 默认（Electron / 现代 Chromium WebView） | 全部材质，含 backdrop-filter |
| `plain` | 弱设备：`deviceMemory < 4` 或 `hardwareConcurrency < 4` | 去掉 backdrop-filter，染色加重 |
| `opaque` | 用户开"减弱透明" / 系统 `prefers-reduced-transparency` | 全部不透明底 + 硬边，**布局零位移** |

按硬件能力而不是按宿主判断：静态 `backdrop-filter` 在 Chromium WebView 里是能正常渲染的，
真正会掉进软件合成路径的是**弱设备**。必须由平台判定，**不能靠 `@supports`** ——
浏览器能"成功解析"一个它根本不渲染的滤镜值。

### 2.4 性能预算

成本 ≈ `(w + 6r)(h + 6r)`：**半径几乎免费，面积才是钱**。一层满高侧栏的模糊采样面积比其余 chrome 总和还大，所以它永远不是玻璃。

- 同时存在的 `backdrop-filter` 层：桌面 ≤ 4，手机 ≤ 2。
- 全项目只有 5 处真模糊：手机顶栏、手机 dock、手机 FAB、桌面详情栏的顶栏与底栏。
- 透镜**不带**模糊（它跑在静态纸面上，模糊零收益）。

## 3. 令牌（`src/renderer/src/tokens.css`，唯一来源）

组件里写死颜色/字号/时长视为缺陷。常用：

```
颜色     --bg-base --surface --surface-2 --surface-3 --panel
         --text --text-dim --text-faint --accent --accent-text --accent-soft
         --event --danger --hairline --hairline-strong
材质     --mat-veil --mat-grad --rim-inset --rim-lo --vignette --grain-opacity
         --glass-blur --glass-sat --scrim-dim
字阶     --fs-display 30 / --fs-title 17 / --fs-body 13 / --fs-label 12
         --fs-caption 11 / --fs-micro 10（手机端 body 15）
间距     --s-1 2 --s-2 4 --s-3 6 --s-4 8 --s-5 12 --s-6 16 --s-7 20 --s-8 24 --s-9 32
圆角     --r-chip 6 --r-control 10 --r-card 14 --r-panel 20 --r-window 28 --r-pill 999
阴影     --e1 抬起 / --e2 浮层 / --e3 弹窗
```

排版规则：**中文一律 `letter-spacing: 0`**（加字距立刻变廉价），只有拉丁大字号用 `--tracking-display`；所有数字 `font-variant-numeric: tabular-nums`。

字体只能用系统栈 —— CSP 是 `default-src 'self'`，没有网络字体，也没有打包字体文件。

## 4. 动效（`design/motion.css` + `tokens.css`）

### 4.1 两套方言，永不混用

- **空间类**（位移 / 缩放 / 变形 / 展开）：弹簧，参数是「阻尼比 ζ + 响应时间 τ」，采样成 CSS `linear()`。
- **非空间类**（透明度 / 颜色 / 删除线）：短曲线。**永远不要把 alpha 挂在弹簧上。**

| 令牌 | 曲线 | 时长 | 用在哪 |
| --- | --- | --- | --- |
| `--ease-spatial` | ζ0.99 / τ380ms，0% 过冲 | `--t-spatial` 500ms | 面板进出、抽屉、换页位移 |
| `--ease-pill` | ζ0.72 / τ450ms，3.8% 过冲 | `--t-pill` 540ms | 选中透镜 |
| `--ease-pop` | ζ0.86 / τ260ms | `--t-pop` 340ms | 勾选、chip、菜单项、卡片入场 |
| `--ease-micro` | `cubic-bezier(.3,.5,.7,1.2)` | `--t-micro` 150ms | 今天圈、勾号 |
| `--ease-alpha` | `cubic-bezier(.33,0,.2,1)` | `--t-alpha` 200ms | 透明度、颜色 |
| `--ease-press` | 弹簧 311/.593 | `--t-press` 240ms | `:active` 回弹 |
| `--ease-travel` | FlClash travel | `--t-travel` 412ms | 抽屉、菜单位置 |

档位只有四档：`--t-tap 100` / `--t-fast 150` / `--t-base 200` / `--t-page 300`，其余都是具名令牌。

**老 WebView 回退**：`@supports not (transition-timing-function: linear(0,1))` 时换成等价贝塞尔。必须写 —— `linear()` 不支持时整条 `transition` 简写会被判无效，所有弹簧变成瞬切且**没有报错**。

### 4.2 三条硬规则（code review 逐条查）

1. 带 `backdrop-filter` 的元素**及其任何祖先**，只允许动 `transform` 和 `background-color`。动 `opacity` / `filter` / `mask` / `clip-path` 会让它变成 backdrop root，玻璃在整段动画里彻底失效，结束后"啪"一下出现。
2. **永远不 `transition: backdrop-filter`**（不插值，结束才跳）。
3. **不动 `width` / `height` / `top` / `left`**。唯一例外：列表删除时的高度塌陷。

### 4.3 逐交互规格

| 交互 | 规格 |
| --- | --- |
| 翻月 / 切 tab | 出 12px 单轴 + 淡出 120ms；进回 0 + 淡入 240ms；方向由事件处理函数显式给出 |
| 选中某天 | 透镜用 `--ease-pill` 追过去（`@property` 注册的 `--lens-c` / `--lens-r` 驱动 `translate(%)`，不需要 JS 量格子） |
| 勾选完成 | 勾 `micro-pop` 150ms；删除线 `scaleX 0→1` 300ms，origin left，暖色→灰渐变；文字变灰同步 |
| 新建任务 | 行入场 `pop-in`，其余行用 `layout` 弹簧让位 |
| 打开面板 | 位移走 `--ease-spatial`；遮罩：内容层 `filter: blur()`（WebView 里只有它逐帧渲染）+ 压暗，只动 `background-color` |
| 弹层 | 从触发点方向 `scale .92→1 + y 8→0` 340ms；条目 24ms 错开 |
| 按压 | 格子 `.994`、按钮 `.96`、FAB `1.04`，240ms |
| 悬停 | 150ms 颜色；玻璃面额外跑指针高光（`--mx/--my`，一帧只写一次，仅 `pointer:fine`） |

### 4.4 无障碍

- `prefers-reduced-motion`：`base.css` 把时长、延迟、迭代次数全部压到 1ms，并且**连 `animation-delay` 一起归零**（只改 duration 的话，错开出现的元素会一个一个蹦出来）。
- `prefers-contrast: more`：去掉颗粒、加硬边、降饱和。
- `forced-colors: active`：强制关掉 `backdrop-filter` 和所有阴影，否则文字会飘在内容上。
- 玻璃面**最多两级文字**（`--text` / `--text-dim`）。更多层级在透明底上过不了 4.5:1。

## 5. 加新组件的顺序

1. 先问它属于哪一层（L1 内容 / L3 chrome）。**默认是 L1**，只有导航与控件才配玻璃。
2. 布局只用 `--s-*` 与 `--r-*`；颜色只用令牌；数字加 `tabular-nums`。
3. 动效从 §4.3 里挑一行，指不到某一行就说明这个动效不该加。
4. 需要一个容器就复用 `.mat-surface` / `.mat-chrome`，不要重写玻璃配方。
5. 每个交互都要能在 `prefers-reduced-motion` / `data-mat="plain"` / `data-glass="opaque"` 三种状态下保持布局不变。
